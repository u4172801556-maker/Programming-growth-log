## Why I Am Learning Programming

Recently, many coding agents have appeared, including Codex, Cursor, Trae, Lovable, Magic Patterns, Devin, Replit Agent, and Factory Droid.

I have tried some of these tools. In many cases, my main task is to describe what I want clearly, and the agent can generate something that I can evaluate. This experience is often called “vibe coding,” and it is especially appealing to people like me who have little programming experience.

However, I have also noticed a problem. When a coding agent makes a mistake, I may not know which part of the code is wrong or which commands I should run to fix it. The process can feel like a black box: I can describe a goal and receive a result, but I do not yet understand everything that happens in between.

This is one reason I want to learn programming. I do not necessarily want to write every line of code by myself. Instead, I want to understand enough to:

- judge whether the generated code is useful
- identify mistakes and possible risks
- explain what the code is doing
- modify simple parts of the code
- communicate more effectively with coding agents

As coding agents become more widely available, I also wonder about their long-term impact. If everyone can use similar tools, will software development become cheaper and more competitive? Will coding agents replace some human work, or will they mainly amplify what people can do?

I do not know the answers yet. I am learning programming partly to explore these questions from a more informed position, rather than treating coding agents as a completely mysterious black box.

I do not necessarily want to write every line of code by myself. Instead, I want to understand enough to judge, debug, and guide the code.
## What I mean by useful programming

For me, useful programming does not necessarily mean building a large or complicated application.

A program is useful if it can:

- solve a real problem
- save time or effort
- make learning easier
- organize information
- help me understand an idea
- help another person in some way

I will try to discover what useful programming means through small projects and experiments.
